# Demo Script (under 3 minutes)

One story, one evening, one household. Every number on screen, including every dollar figure, comes from the cited scenario run (`scenarios/demo-evening.yaml`, seed 20261013) against real ComEd prices and Open-Meteo weather, and maps to an audit row. No savings figure is typed into a caption, the README, or the Devpost description; if the run says $1.40, the video says $1.40. Recorded from the Haven Simulator in Echo Show mode, with one beat in Echo Dot (voice-only) mode to prove voice completeness. Each beat proves one thing; the wearable "Recovery Morning" line and the AWS console tour were cut on 2026-09-16 because neither is scored from the video (the wearable twin stays in the product and the scenario; the console goes to the image gallery). The companion app appears in a second window where the constitution and audit trail are shown.

Judges are not required to watch past 3:00 or to run anything, so the video must carry the whole case.

**Rules honored:** no third-party trademarks beyond the sponsor's platform (the car is "the car"; no wearable appears in the video), no copyrighted music, English, project shown functioning on the intended surface, a visible `twin`/`real` badge wherever data is simulated or live.

## Production notes

- Record the simulator at 1920×1080 with the transcript pane visible; the tool calls are the technical evidence.
- Use `haven scenario step --to` to pause before each beat; the clock speed is 60× between beats and 1× during speech.
- The overnight dishwasher is an ASK under the household's own `appliance_start` rule (ask outside 07:00–22:00) and quiet hours; the 11:30 pm voice approval is what lets it run at 4:30 am. This is the spine of the video: the rule shown at 0:45 is the rule that asks at 1:55 and the rule whose Cedar appears at 2:20.
- Captions for every spoken line (accessibility and judges on mute).
- Voice: the simulator's TTS for Alexa; the author's own voice for Malik and Dad, or two captioned text turns if preferred.
- The phone mock-up for Dad's check-in and for Malik's unlock approval is the companion app in a phone-width browser window.
- Keep the AWS console cut under 8 seconds; the point is that it exists and matches, not a tour.
- Export with the scenario run id in the description; the README links the run's audit export so anyone can verify the numbers.
